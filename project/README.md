# Yes, Cloth — Frontend (Create React App)

## เทคโนโลยีที่ใช้
- React 18
- React Router DOM 6
- Tailwind CSS ผ่าน CDN (คงรูปแบบเดิมของเว็บไซต์)
- Create React App (`react-scripts`)

## วิธีติดตั้งและเปิดโปรเจกต์
ต้องติดตั้ง Node.js ก่อน จากนั้นเปิด Terminal ที่โฟลเดอร์โปรเจกต์แล้วรัน

```bash
npm install
npm start
```

เว็บไซต์จะเปิดที่ `http://localhost:3000`

## สร้างไฟล์สำหรับนำขึ้นออนไลน์

```bash
npm run build
```

ไฟล์เว็บไซต์ที่ build แล้วจะอยู่ในโฟลเดอร์ `build/`

## ขอบเขตการทำงาน

### Guest
- ดูหน้าแรกและรายการสินค้า
- เลือกดูสินค้าตามหมวดหมู่และค้นหาสินค้า
- ดูรายละเอียดสินค้าและรีวิว

### Member
- สมัครสมาชิก / เข้าสู่ระบบ
- เพิ่มรายการโปรด
- เพิ่มสินค้าลงตะกร้า
- ยืนยันคำสั่งซื้อโดยไม่ต้องกรอกที่อยู่หรือชำระเงินจริง
- ดูประวัติคำสั่งซื้อและเขียนรีวิวแบบเลือกดาว

### Admin
- Dashboard แสดงจำนวนสินค้า คำสั่งซื้อ สมาชิก และยอดขาย
- จัดการสินค้า เพิ่ม / แก้ไข / ลบ
- ดูตัวอย่างรูปภาพทันทีเมื่อใส่ URL รูปภาพ
- ดูหมวดหมู่ คำสั่งซื้อ สมาชิก และรีวิว
